# Pathmora × LinguaFlow × LinguaFlow-Reader：一个闭环的英语学习系统

> 面向使用者的一份说明：这三个系统各自做什么、如何串成闭环、怎么用、背后的科学原理是什么，以及它和 LingQ / 多邻国 / Trancy 等市面产品的区别。
> 最后给出把 **Trancy（视频学习）** 纳入你个人学习栈的实操方案。

---

## 0. 一句话总览

**Reader 负责「在真实语境里遇到语言」，LinguaFlow 负责「账号 + 词典 + 数据底座」，Pathmora 负责「记住你学过什么、并决定下一步学什么」。** 三者共用一个账号、一份学习记录，形成「输入 → 捕获 → 记录 → 调度 → 复习 → 再输入」的闭环；阅读不是任务，而是闭环给你的**奖励**。

```
                 ┌────────────────────────────────────────────┐
                 │            PATHMORA（学习大脑）             │
                 │  唯一学习记录 · 复习调度 · 学习计划 · 账号源   │
                 └───────────────▲──────────────┬─────────────┘
            上报学习事件          │              │  下发「今日10分钟」
   (lookup/save_sentence/        │              │  + 阅读奖励15分钟
    shadow/review)               │              ▼
                 ┌───────────────┴──────────────┐
                 │        LINGUAFLOW（底座）      │
                 │  统一账号 · 共享词典 · /learn   │
                 │  事件存储 · /learn/summary     │
                 └───────────────▲──────────────┘
                                 │  查词 / 同步（opt-in）
                 ┌───────────────┴──────────────┐
                 │     LINGUAFLOW-READER（现场）  │
                 │  阅读捕获 · 跟读练习 · 复习执行 │
                 │  难度匹配选书 · 本地优先        │
                 └──────────────────────────────┘
                        阅读 = 奖励（i+1 匹配的书）
```

## 1. 三个系统各自的分工

### 1.1 LinguaFlow-Reader —— 学习现场（输入 + 捕获 + 练习）

- **本地优先的 EPUB 阅读器**：书籍文件只留在你的设备；默认空书架，自己用文件夹 / 拖拽 / 多选导入 EPUB/TXT/MD。
- **捕获**：点词查义（本地词库 → 共享服务器英汉词典 → 免费词典三级）、收藏「你遇到的那句句子」、划线标记。句子是贯穿三系统的**原子单位**。
- **练习**：口语实验室（原句跟读 / 盲听复述 / 自由独白），带韵律反馈、可懂度信号、焦点式纠错、自我监控、间隔重录、复杂度维度。
- **复习执行**：主动复习页执行 Pathmora 下发的顺序；不可达时本地 SRS 降级，阅读不被阻塞。
- **难度匹配**：按你的已知词计算每本书的词频加权覆盖率，90–98% 标为 i+1，并给「今日推荐」。
- **上报（可选）**：只有你显式开启「同步学习记录」，才把 lookup/save_sentence/shadow/review 事件上云；书籍文件永不上传。

### 1.2 LinguaFlow —— 底座（账号 + 词典 + 数据）

- **统一账号**与**共享词典**：英语 ECDICT 约 39.5 万词（另日/韩/西），`GET /dict/lookup` 公开只读、跨域开放，三产品共用，不「一个词调一次大模型」。
- **学习事件存储**：`POST /learn/events` 接收 Reader 上报；`GET /learn/summary` 汇总已知词 / 薄弱词 / 收藏句 / 跟读指标 / 活跃天数。
- 它是「数据管道 + 公共基础设施」，**不做复习调度**——调度归 Pathmora。

### 1.3 Pathmora —— 学习大脑（记录 + 调度 + 计划）

- **唯一记录学习记录**的地方：只有它知道你的全量历史，因此能制定跨产品的计划。
- **复习调度**：把薄弱词（答错/困难）优先、已知词间隔强化，排成「今日 10 分钟」。
- **阅读是奖励**：计划里明确保护阅读时间（如 15 分钟），读的是难度匹配的书——复习是为了让你读得更爽，而不是取代阅读。
- **账号源**：统一登录以 Pathmora 为准，LinguaFlow 桥接，Reader 复用同一 token。
- 当前以**独立微服务**（`/api/reader/plan`）下发计划，主产品不受影响；未来可并回主进程。

> 分工原则：**Reader 不当复习调度器，LinguaFlow 不做大脑，Pathmora 不碰阅读现场。** 各司其职，靠契约（事件 + 汇总 + 计划）连接。

## 2. 闭环如何转起来

1. **读**：在 Reader 打开一本 i+1 的书，大量可理解输入。
2. **捕获**：遇到生词点一下、把有用的句子收藏下来（句子 = 原子单位）。
3. **记录**：事件（opt-in）经 LinguaFlow 存入你的学习记录。
4. **调度**：Pathmora 读汇总，把「薄弱词 + 该强化的词」排成今日复习队列。
5. **复习/练习**：Reader 复习页执行队列；口语实验室把收藏句子拿来跟读。
6. **反馈**：复习结果回传 → 已知词增长 → 覆盖率变化 → **难度匹配推荐下一本书**。
7. **奖励**：你带着更大的词汇量去读下一本 i+1 的书——阅读本身就是奖励，回到第 1 步。

关键设计：**复习服务于阅读，阅读驱动复习**。两者不是竞争时间，而是互相供给。

## 3. 怎么用（实操）

### 3.1 起步
1. 在 Reader 设置页用 **Pathmora 账号**登录（统一账号）。
2. 打开「同步学习记录」开关（默认关；书籍仍只在本机）。
3. 把 EPUB 放进 `~/Documents/linguaflow-books/`，用「选择书籍文件夹」批量导入。

### 3.2 每天
- **读 15–30 分钟**：读「今日推荐」的 i+1 书；点词、收藏句子，不打断节奏。
- **复习 10 分钟**：复习页执行 Pathmora 队列（先薄弱词后强化）。
- **跟读 5–10 分钟**：口语实验室挑 1–3 句收藏句子跟读，看焦点反馈，一次只改一个问题。

### 3.3 每周
- 看统计页的覆盖率 / 连续天数 / 顽固错词，调整选书难度。
- 用「间隔重录」在 1/3/7 天复录同一句，观察进步。

## 4. 科学原理

| 原理 | 内容 | 在系统里的落地 |
| --- | --- | --- |
| **可理解输入 / i+1**（Krashen） | 略高于现有水平的输入最有效 | 覆盖率 90–98% 判 i+1，难度匹配选书 |
| **词汇覆盖率**（Nation；Hu & Nation 2000） | 98% 才能无辅助流畅理解并附带习得；95% 需辅助 | 词频加权覆盖率 + 已知词驱动选书 |
| **泛读 / 大量输入**（Nation） | 词汇与语感的主引擎是大量意义导向阅读 | 阅读是奖励、保护阅读时间 |
| **间隔重复**（Ebbinghaus；SM-2/Leitner） | 在将忘未忘时复习最省时间 | 复习 SRS + 间隔重录 1/3/7 天 |
| **提取练习 / 测试效应**（Roediger & Karpicke 2006） | 主动回忆比被动重读更巩固 | 闪卡先回忆再揭示、原文挖空、句子回译 |
| **语境化词汇 / 句子挖掘** | 词在句子里才被真正学会 | 句子为原子单位，查词带原句、收藏句进复习 |
| **听读结合** | 边听边读提升流畅度与动机 | 有声书边听边看、页码锚点 |
| **跟读 / 韵律训练** | 模仿节奏重音改善口语可懂度 | 韵律反馈、可懂度信号、焦点纠错 |
| **自我决定论 / 内在动机** | 自主与胜任感比外部奖惩更持久 | 阅读=奖励、无强制打卡、诚实指标 |
| **元认知 / 自我监控** | 先自评再对照，校准自我认知 | 跟读先自评再显示系统反馈 |
| **复杂度（CAF）** | 句长/从句/多样性反映输出发展 | Free Talk 复杂度维度（诚实标注≠好坏） |

> 诚实边界：韵律相似度≠发音正确度；复杂度≠好坏；覆盖率是选书参考而非绝对门槛。系统给信号，不替你下结论。

## 5. 与市面产品的区别

| 产品 | 强项 | 局限 | 本系统的不同 |
| --- | --- | --- | --- |
| **LingQ** | 词状态(new→known)+SRS+已知词计数 | 阅读单腿、付费、口语/计划弱 | 三产品闭环：阅读+口语+统一大脑调度 |
| **多邻国** | 游戏化、易上手 | 翻译 drills 非真实阅读、外部动机(连击) | 真实语境输入、阅读=奖励、无强制打卡 |
| **Readlang** | 网页点词 | 无原生手机、无调度 | 本地优先+统一复习大脑 |
| **Beelinguapp** | 双语平行+音频 | 封闭书库 | 自带书+难度匹配 |
| **Kindle** | Vocab Builder | 闪卡退役、注释非翻译 | 句子级捕获+主动复习 |
| **Simply Fluent** | 释义常驻 | 单阅读工具 | 常驻注音+词状态+闭环 |
| **蒙哥/薄荷/扇贝** | 分级/打卡 | 打卡易异化、数据孤岛 | 阅读=奖励、跨产品一份记录 |
| **Trancy** | 视频双字幕+AI 句析 | 视频单通道、无统一复习大脑 | 作为视频输入腿接入你的栈（见 §6） |

**核心差异**：
1. **一个大脑**：市面工具各自记各自的生词本；这里只有 Pathmora 记全量学习记录并统一调度。
2. **句子是原子单位**：查词、收藏、跟读、复习都围绕「你遇到的那句句子」，而非孤立单词。
3. **阅读是奖励**：计划保护阅读时间，复习为阅读服务，逆转「打卡换阅读」的异化。
4. **本地优先 + 可选上云**：书籍永不上传；学习记录同步是显式 opt-in。
5. **诚实指标**：不假装韵律=发音、复杂度=好坏，给信号而非虚假分数。

## 6. 把 Trancy 纳入你的学习栈（视频腿）

你接下来会用 **Trancy** 看视频练英语。它和本系统**互补而非竞争**：Trancy 提供「视频/听力」的真实输入，本系统提供「阅读 + 口语 + 统一复习」。

### 6.1 各通道分工
- **Trancy（视频/听力）**：YouTube/Netflix 双字幕、点词、AI 句析 → 大量可理解**听**输入 + 视觉语境。
- **Reader（阅读）**：书籍深读 → 可理解**读**输入 + 句子捕获。
- **口语实验室（说）**：跟读/复述 → 输出练习。
- **Pathmora（大脑）**：把各通道产生的生词/句子统一调度复习。

### 6.2 实操闭环（含 Trancy）
1. 用 Trancy 看一集视频，开双字幕，点生词、收藏好句。
2. 把 Trancy 里收藏的句子/生词，**手动**补进 Reader（收藏句子/词汇本），或直接作为口语实验室的跟读素材。
3. 事件经 opt-in 同步进入 Pathmora，与阅读产生的记录合并调度。
4. 复习页统一复习「视频 + 阅读」两路来的词；跟读练视频原句。
5. 已知词增长 → 阅读覆盖率上升 → 读更难的書；听力同理逐步关字幕。

> 现状说明：Trancy 目前**未与本系统自动打通**，第 2 步为手动桥接。未来可把 Trancy 导出（句子/生词）做成 Reader 的导入源，实现自动汇入闭环——这是自然的下一步集成。

### 6.3 一周示例
- 周一/三/五：Trancy 视频 20 分钟（听力输入）+ 复习 10 分钟。
- 周二/四：Reader 阅读 20 分钟（阅读输入）+ 跟读 10 分钟。
- 周末：统计页复盘 + 间隔重录 + 自选一本 i+1 新书。
