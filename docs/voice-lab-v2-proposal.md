# 口语实验室 v2 · 产品方案（科学依据版）

> 目标：把「说得多快、多顺、多长」的现状，升级为「说得好不好懂」的完整闭环。
> 原则：**可懂度优先于母语口音**；**诚实反馈，不伪造音素评分**。

---

## 0. 一句话结论

现有口语实验室已经扎实覆盖了**流畅度（fluency）**与**产出量（output）**，最大缺口是**韵律与可懂度（prosody & intelligibility）**。本次升级的核心，不是加更多指标，而是补上这一维，并把反馈从「整段全量」改成「一次一个点」，让每个练习循环都能被大脑记住。

---

## 1. 现状盘点

| 能力维度 | 现有实现 | 覆盖度 |
|---|---|---|
| 流畅度 | WPM、卡顿占比、口头禅统计 | ✅ 已覆盖 |
| 产出量 | 录音时长、词数、年度热力图、30 天曲线 | ✅ 已覆盖 |
| 词级准确 | Levenshtein 词级 diff（匹配/低置信/漏读替换） | 🟡 部分（只测词，不测音） |
| 韵律 | 无 | ❌ 缺失 |
| 可懂度 | 无（diff 的 substitute 隐含了「听错」，但未显式呈现） | ❌ 缺失 |
| 复杂度 | 无（只有 wordCount） | ❌ 缺失 |

三种模式（Shadowing / Cloze Retell / Free Talk）与双引擎转写（原生 STT / 本地 Whisper）定位正确，保留。

---

## 2. 科学框架（为什么这么改）

| 理论 | 出处 | 对本产品的含义 |
|---|---|---|
| **CAF 三元** | Housen & Kuiken (2009) | 复杂度 / 准确度 / 流畅度是语言产出的三个独立维度，目前只测了后两个 |
| **可懂度优先** | Levis (2005) · Jenkins (2000, LFC) | 目标是被听懂，不是像母语者；重音与节奏比单音素更影响可懂度 |
| **重音计时 vs 音节计时** | Pike (1945) · Abercrombie (1967) | 英语 stress-timed、中文 syllable-timed——中文母语者最易暴露、最影响可懂度的点 |
| **注意假说** | Schmidt (1990) | 「注意到差距」是习得前提；全量标红 = 什么都没注意到 |
| **认知负荷** | Sweller (1988) | 一次只给一个纠正点，否则工作记忆过载 |
| **自我监控** | Kormos (2006) | 先听自己 → 再对比 → 再修正的闭环，优于被动看分数 |
| **分散练习 / 检索** | Cepeda et al. (2006) · Roediger & Karpicke (2006) | 隔天重录同一句，比当场录十遍记得牢 |
| **语音环路** | Baddeley (2000) | 跟读记忆跨度（递增句长）训练语音工作记忆 |

## 4. 改进方案（按优先级分层）

### Tier 1 · 补最大缺口

> **实现状态（2026-11-13）**：① 韵律反馈与 ② 可懂度简单档已上线。
> 代码：`src/lib/prosody.ts`（`wordFeaturesFromBuffer` / `classifyProsody` / `intelligibilityGaps`）+ `src/components/VoiceRecorder.tsx`（解码原音/录音→逐词能量/浊音对齐；可懂度面板）。
> 逐词边界采用「浊音区间等分」（无 Whisper word timestamps 的稳妥近似）；韵律输出标注「节奏相似度，非发音正确度」。
> ② 进阶档（token logprob）与 Tier 2/3 仍待后续。算法有 node 单测；麦克风链路在无头 headless-shell 无法跑 E2E（fake device 不生效），故以单测+构建+线上加载验证。

#### ① 韵律反馈 · prosody shadowing ｜ 优先级 P0

- **科学依据**：英语重音计时，中文音节计时；重音（更长 + 更响 + 音高更高）是中文母语者最痛的点。
- **功能**：Shadowing 模式下，把「原音 vs 你的录音」做**逐词重音强弱 + 时长**对齐，标出：
  - 🔴 该重读却弱读的词
  - 🟡 该弱读却拖长的词
  - 🟢 节奏匹配的词
- **技术可行性**：✅ 纯前端。Web Audio 解码两端音频 → 能量包络 + 时长对齐。原音的逐词时间边界可用 Whisper 的 word timestamps，或简单等分。**不需要音素模型，不需要后端**。
- **诚实边界**：输出是「节奏相似度」，不是「发音正确度」，文案明确标注。

```
[线框 · 韵律对比条]
TARGET  "the WORLD is not FINISHED being interesting"
YOURS   "the world is not FINISHED being interesting"
        ──  ──    ──  ──  ────────  ──  ──
             ▲                    ▲
        "WORLD 应重读"      "interesting 弱读拖长"
[图例] 🟢 节奏匹配  🟡 弱读/拖长  🔴 重音缺失
```

#### ② 可懂度信号 · intelligibility ｜ 优先级 P0（可与①并列）

- **科学依据**：可懂度优先——「机器听没听懂」是真实的可懂度代理。
- **功能**：把 diff 里的 `substitute` / `missing` 词显式呈现为「这里可能没被听懂」，引导重读；进阶版用 Whisper 的 token logprob 给置信度。
- **技术可行性**：
  - 简单档 ✅ 现在就能做（复用现有 diff 的 substitute/missing）。
  - 进阶档 🟡 需验证 `@huggingface/transformers` 是否暴露 token 级 logprob（whisper generate 的 `output_scores`）。
- **诚实边界**：文案是「机器可能没听清」，不是「你读错了」。

```
[线框 · 可懂度提示条]
⚠ 有 2 个词可能没被听懂：
   · "curiosity" — 识别成了 "curious"（低置信）
   · "asks"     — 未识别到
[按钮] 重读这两个词  ·  听标准音
```

### Tier 2 · 反馈设计优化（不改模型，改「怎么给反馈」）

> **实现状态（2026-11-13）**：③ 焦点式纠错 + ④ 自我监控已上线（Tier 2 完成）。
> ③ `src/lib/focus.ts` `pickFocus` 按「漏读→重音弱→拖长→停顿→口头禅→替换」优先级选出本轮唯一焦点；VoiceRecorder 渲染焦点卡 +「下一轮只练这个」→ 目标文本高亮焦点词 + 下一轮提醒条。
> ④ 录音后先弹「你觉得自己哪里没跟上？」自评（`SELF_OPTIONS`），再展开 diff/韵律/可懂度/焦点；`selfCompareText` 对比自评与系统焦点的一致性。可「跳过自评」。

#### ③ 焦点式纠错 · one thing at a time ｜ 优先级 P1

- **科学依据**：注意假说 + 认知负荷——一次只纠一个点。
- **功能**：每轮练完，从「漏读词 / 重音错误 / 停顿位置 / 口头禅」里，**自动选出一个**最该改的点，作为「本轮唯一焦点」，下一轮只盯它。
- **技术可行性**：✅ 纯前端逻辑，对 diff/metrics 做优先级排序。

```
[线框 · 焦点卡]
本轮只盯一个点
┌──────────────────────────────┐
│  你的 "world" 重音弱了 1 次    │
│  下一轮：说重一点、拉长一点    │
│        [下一轮只练这个]        │
└──────────────────────────────┘
```

#### ④ 自我监控回路 · self-monitoring ｜ 优先级 P1

- **科学依据**：自我监控是发音习得的关键闭环。
- **功能**：录音后**先不展示 diff**，弹出「你觉得自己哪里没跟上？」自评一句，再展开对比，最后对比你的自评和系统判断。
- **技术可行性**：✅ 纯 UI 流程改动，时间胶囊 A/B 已有数据基础。

### Tier 3 · 机制升级（把一次性练习变成会重复的系统）

#### ⑤ 间隔重录 · spaced shadowing ｜ 优先级 P2

- **科学依据**：分散练习 + 检索，隔天重录比当场重复更牢。
- **功能**：同一句话按 1/3/7 天间隔回到练习队列，看 WPM / 节奏进步曲线。
- **技术可行性**：✅ 纯前端，voiceRecords 按 targetText 分组 + 到期触发器（localStorage/IndexedDB）。

#### ⑥ 复杂度维度 · complexity ｜ 优先级 P3

- **科学依据**：CAF 三元补全。
- **功能**：Free Talk 测句长、从句占比、词汇多样性（type-token ratio）。
- **技术可行性**：✅ 纯前端统计，诚实标注「复杂度≠好坏」。

## 7. 红线与诚实边界（不可违反）

1. **不伪造音素评分**。所有发音维度的输出，只呈现「节奏相似度」「机器是否听懂」，绝不产出「你音标 87 分」这类伪精确。
2. **可懂度优先**。文案始终引导「被听懂」，不引导「像母语者」。
3. **一次一个点**。默认不整段全量标红。
4. **纯前端、无后端、数据在本机**。与 LinguaFlow Reader 现有架构一致。
5. **STT 不恢复**（针对主项目口径）；本项目的 Whisper/原生 STT 是既有核心能力，不新增引擎。
